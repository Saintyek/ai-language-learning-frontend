## Mock Strategies

| 层级 | Mock 方法 | 说明 |
|------|-----------|------|
| **API 调用** | Mock `fetch` 或使用 MSW | 使用 Mock Service Worker 模拟后端响应 |
| **Hooks** | `@testing-library/react-hooks` | React Hooks 测试工具 |
| **分词器** | 直接单元测试 | 纯函数，可直接测试 |
| **DOM 事件** | `@testing-library/user-event` | 用户交互模拟 |

**示例 Mock 配置：**
```typescript
// __mocks__/fetch.ts
export const mockFetch = (response: any) => {
  global.fetch = jest.fn(() =>
    Promise.resolve({
      ok: true,
      json: () => Promise.resolve(response),
    })
  )
}
```

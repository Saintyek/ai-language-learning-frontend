### Observer Pattern (观察者模式)

**Source**: `src/pages/Chat/components/ChatDialogArea.tsx:90-119` [Code Direct]
**Scanned**: 2026-05-06

**目的：** 监听 DOM 变化，在聊天内容更新时自动处理文本节点。

**实现方式：**
```typescript
const observer = new MutationObserver(mutations => {
  for (const mutation of mutations) {
    if (mutation.type === 'childList' && mutation.addedNodes.length > 0) {
      const hasOurSpans = Array.from(mutation.addedNodes).some(
        node =>
          node instanceof HTMLElement && node.hasAttribute && node.hasAttribute('data-word')
      )
      if (!hasOurSpans) {
        processNodes()
      }
      break
    }
  }
})

observer.observe(container, {
  childList: true,
  subtree: true,
})
```

  globalClickCallback = callback

  event.stopPropagation()
  event.preventDefault()

  }
})

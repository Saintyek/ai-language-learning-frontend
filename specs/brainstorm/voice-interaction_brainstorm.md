## 需求背景

实现语言学习应用的语音交互功能，支持用户通过语音进行对话练习，并获得发音分析反馈。

**核心需求**：
1. 点击麦克风按钮录音
2. 语音转文字并自动发送
3. AI进行文字回复和语音回复
4. 分析用户发音质量

**API选型结论**：
- 现有的语音合成API（HTTP Chunked单向流式）**无法满足需求**，因为不支持语音识别（ASR）和实时对话
- **必须使用端到端实时语音大模型API（RealtimeAPI）**，它提供完整的ASR+对话+TTS能力

## 技术方案

### 方案选择：后端转发模式

**架构设计**：
```
前端 <--WebSocket--> 后端 <--WebSocket--> 火山引擎RealtimeAPI
```

**方案优势**：
- 端到端流式交互，延迟低
- 安全性好，API Key保存在后端
- 可复用现有架构
- 发音分析易于实现

### 技术栈

| 层级 | 技术 |
|-----|------|
| 前端 | React + TypeScript + WebSocket API + MediaRecorder API |
| 后端 | NestJS + WebSocket Gateway + @nestjs/websockets |
| 第三方API | 火山引擎端到端实时语音大模型API |
| 音频格式 | PCM（16kHz, 16bit, 单声道）|

const useVoiceRecorder = () => {
  const [isRecording, setIsRecording] = useState(false)
  const mediaRecorderRef = useRef<MediaRecorder | null>(null)

  const startRecording = async () => {
    const stream = await navigator.mediaDevices.getUserMedia({
      audio: {
        sampleRate: 16000,
        channelCount: 1,
        echoCancellation: true,
        noiseSuppression: true
      }
    })
    const mediaRecorder = new MediaRecorder(stream, {
      mimeType: 'audio/webm;codecs=pcm'
    })
    mediaRecorderRef.current = mediaRecorder
    mediaRecorder.start(20) // 20ms一包
    setIsRecording(true)
  }

  const stopRecording = () => {
    mediaRecorderRef.current?.stop()
    setIsRecording(false)
  }

  return { isRecording, startRecording, stopRecording }
}
```

// voice.gateway.ts
@WebSocketGateway({
  path: '/voice',
  cors: true
})
export class VoiceGateway implements OnGatewayConnection, OnGatewayDisconnect {
  @WebSocketServer()
  server: Server

  handleConnection(client: Socket) {
    // 初始化火山引擎连接
    const realtimeService = new VolcengineRealtimeService()
    client.data.realtimeService = realtimeService

    // 转发火山引擎事件到前端
    realtimeService.onMessage((event) => {
      client.send(JSON.stringify(event))
    })
  }

  @MessageHandler('audio')
  handleAudio(client: Socket, data: Buffer) {
    // 转发音频到火山引擎
    client.data.realtimeService.sendAudio(data)
  }
}
```

#### B3: 发音分析服务

**新增文件**：
- `src/voice/pronunciation-analysis.service.ts` - 发音分析服务

**实现方式**：
1. 获取用户发音识别文本（ASR结果）
2. 获取用户应该说的标准文本（来自对话上下文）
3. 计算相似度评分（使用编辑距离算法）
4. 识别问题音素（对比差异）
5. 生成简单改进建议

```typescript
// pronunciation-analysis.service.ts
export class PronunciationAnalysisService {
  analyze(userText: string, standardText: string): PronunciationResult {
    // 计算相似度
    const similarity = this.calculateSimilarity(userText, standardText)
    const score = Math.round(similarity * 100)

    // 识别问题
    const problems = this.identifyProblems(userText, standardText)

    return {
      score,
      problems,
      suggestion: this.generateSuggestion(problems)
    }
  }

  private calculateSimilarity(text1: string, text2: string): number {
    const distance = this.levenshteinDistance(text1, text2)
    const maxLength = Math.max(text1.length, text2.length)
    return 1 - distance / maxLength
  }
}
```

## 需求概述

在 LLM 流式输出文本时，调用火山引擎语音合成 API 同步流式输出文本对应的音频，实现"边说边播"的实时语音合成能力。

## 技术选型

### 火山引擎 TTS API 选型

经分析三个可用 API，选择 **WebSocket 双向流式-V3**：

| 对比维度 | HTTP Chunked/SSE 单向流式 | WebSocket 单向流式 | WebSocket 双向流式 ✓ |
|---------|--------------------------|-------------------|---------------------|
| 文本输入 | 一次性全部输入 | 一次性全部输入 | 实时流式输入 |
| 适用场景 | 已有完整文本 | 已有完整文本 | 实时交互（LLM流式） |
| 官方推荐 | - | - | 对接大文本模型首选 |

**接口地址**：`wss://openspeech.bytedance.com/api/v3/tts/bidirection`

**官方最佳实践**：在对接大文本模型时，推荐将流式输出的文本直接输入该接口，而不要额外增加切句或攒句的逻辑。

### 架构方案

选择 **后端代理模式**：

```
┌─────────┐     SSE      ┌─────────┐    WebSocket    ┌─────────┐
│  前端   │ ──────────→ │  后端   │ ─────────────→ │ 火山引擎 │
│ Chat    │ ←────────── │ Chat+TTS│ ←───────────── │ TTS API │
└─────────┘   音频SSE   └─────────┘   音频流式返回  └─────────┘
```

**优势**：
- API Key 不暴露给前端，安全性高
- 统一的 SSE 格式，前端实现简单
- 符合项目现有架构（后端统一代理外部 API）

## 详细设计

### 功能点 A1：TTS WebSocket 客户端

#### WebSocket 双向流协议

```
客户端                          服务端（火山引擎）
   │                                │
   │──── StartConnection ──────────→│
   │←─── ConnectionStarted ─────────│
   │                                │
   │──── StartSession ─────────────→│ (携带 speaker, audio_params)
   │←─── SessionStarted ────────────│
   │                                │
   │──── TaskRequest (text) ───────→│ (流式发送文本)
   │←─── TTSResponse (audio) ───────│ (流式返回音频)
   │     ...                        │
   │──── FinishSession ────────────→│
   │←─── SessionFinished ───────────│
   │                                │
   │──── FinishConnection ─────────→│
   │←─── ConnectionFinished ────────│
```

#### 二进制协议帧格式

| 字节 | 说明 |
|------|------|
| 0 | Protocol version (0b0001) + Header size (0b0001) |
| 1 | Message type + Message type specific flags |
| 2 | Serialization method + Compression method |
| 3 | Reserved |
| 4-7 | Event number (optional) |
| ... | Payload |

#### Event 定义

| Event Code | 含义 | 方向 |
|------------|------|------|
| 1 | StartConnection | 上行 |
| 2 | FinishConnection | 上行 |
| 50 | ConnectionStarted | 下行 |
| 52 | ConnectionFinished | 下行 |
| 100 | StartSession | 上行 |
| 102 | FinishSession | 上行 |
| 150 | SessionStarted | 下行 |
| 152 | SessionFinished | 下行 |
| 200 | TaskRequest | 上行 |
| 352 | TTSResponse | 下行 |

### 功能点 A2：TTS SSE 代理 API

#### 端点

`POST /api/tts/stream`

#### 请求参数

```typescript
interface TTSStreamRequest {
  speaker: string       // 音色ID，默认 zh_female_vv_uranus_bigtts
  format: 'mp3'         // 音频格式
  sampleRate: number    // 采样率，默认 24000
}
```

#### 响应格式（SSE）

```
event: audio
data: {"audio": "base64编码的音频数据"}

event: done
data: {}
```

#### 调用链

```
前端 SSE 请求 → TtsController → TtsService → 火山引擎 WebSocket
```

## 风险点

| 风险类型 | 描述 | 缓解措施 |
|----------|------|----------|
| 连接稳定性 | WebSocket 断线 | 实现断线重连机制 |
| 首包延迟 | 约 200-500ms | 提前建立连接，连接复用 |
| 并发限制 | 火山引擎并发限制 | 后端限流，连接池管理 |
| 音频卡顿 | 流式播放可能卡顿 | 音频队列缓冲，预加载策略 |

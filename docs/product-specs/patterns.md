### 3. API 接口设计模式

**Scanned**: 2026-05-06

API 接口采用 Request/Response DTO 模式：

```typescript
// Request DTO
interface TranslateRequest {
  text: string;
  sourceLanguage?: string;
  targetLanguage?: string;
}

// Response DTO
interface TranslateResponse {
  translation: string;
  pronunciation: string;
  example: {
    sentence: string;
    translation: string;
  };
}
```

**决策依据**:
- 类型安全
- 便于文档生成
- 支持验证中间件

# Chat 输入框语音按钮占位设计

## 背景
当前 Chat 页面输入区已经基于 Semi `AIChatInput` 实现，并保留了发送按钮与自定义场景配置区域。用户希望在输入框底部右侧增加一个语音说话按钮，用于后续语音输入能力的入口。

本次只需要先补齐入口 UI，不接入真实录音、麦克风权限申请或语音转文字能力。

## 目标
- 在 `AIChatInput` 底部右侧增加一个语音按钮
- 语音按钮位于发送按钮左侧
- 底部右侧不再展示上传按钮
- 点击语音按钮时给出明确占位反馈
- 保持 Semi `AIChatInput` 现有发送/停止生成逻辑不变

## 非目标
- 不接入浏览器录音能力
- 不申请麦克风权限
- 不实现语音转文字
- 不调整输入框顶部配置区域和场景选择逻辑
- 不修改消息发送、停止生成、流式输出相关逻辑

## 设计结论
采用 `AIChatInput` 的 `renderActionArea` 自定义底部右侧操作区。

操作区只保留两个按钮：
1. 语音按钮
2. Semi 内置发送/停止按钮

上传按钮不再展示。

## 方案选择

### 方案 A：使用 `renderActionArea` 重排底部按钮（采用）
做法：通过 `renderActionArea` 接管 `AIChatInput` 的右侧操作区渲染，只取 Semi 提供的发送/停止按钮节点，再在其左侧插入一个自定义语音按钮。

优点：
- 与 Semi 官方 `AIChatInput` 扩展方式一致
- 不会影响发送按钮内部状态与生成中切换逻辑
- 可以精确控制按钮顺序，并彻底移除上传按钮

缺点：
- 需要手动组织 action area 的节点顺序

### 方案 B：使用 `renderUploadButton` 替换上传按钮
做法：把上传按钮替换成语音按钮。

优点：
- 改动看起来较小

缺点：
- 语义错误，语音按钮不应该挂在 Upload 的行为容器上
- 容易保留或误触上传逻辑
- 无法自然做到“只保留语音按钮 + 发送按钮”

### 方案 C：重写整个输入区底部结构
做法：绕开 `AIChatInput` 默认底部区域，自行实现一套右下角按钮。

优点：
- 自由度最高

缺点：
- 没必要，成本高
- 容易破坏 `AIChatInput` 默认发送/停止生成行为

## 组件设计
修改文件：`src/pages/Chat/components/ChatInputArea.tsx`

### 按钮结构
右侧操作区顺序固定为：
- 语音按钮
- Semi 内置发送/停止按钮

其中发送/停止按钮继续复用 `AIChatInput` 通过 `renderActionArea` 传入的默认按钮节点，不自行重写其行为。

### 语音按钮样式
- 使用 Semi 图标 `IconMicrophoneStroked`
- 使用仅图标按钮样式
- 视觉风格尽量与 `AIChatInput` 默认 footer action button 保持一致
- 与发送按钮保持同一行排列和一致的间距

### 上传按钮处理
通过 `showUploadButton={false}` 隐藏默认上传按钮。

这样 `renderActionArea` 收到的 `menuItem` 中只剩发送/停止按钮，避免额外判断和上传逻辑干扰。

## 交互设计
### 点击语音按钮
点击后触发轻提示：
- `Toast.info({ content: '语音功能开发中' })`

### 发送按钮行为
保持现有行为不变：
- 非生成态时为发送按钮
- 生成态时为停止按钮
- 点击行为仍由 `AIChatInput` 内部处理

## 数据与状态
本次不新增业务状态。

语音按钮是纯占位入口：
- 不新增 `recording` 状态
- 不新增权限状态
- 不增加消息内容结构字段

## 可维护性约束
- 不复制 Semi 发送按钮的实现
- 不修改 `SceneSelector` 和场景选择 hooks
- 不在本次为未来语音能力预埋复杂状态机
- 仅保留一个简单的点击反馈闭环

## 验收标准
1. Chat 输入框右下角显示语音按钮和发送按钮
2. 语音按钮位于发送按钮左侧
3. 上传按钮不再显示
4. 点击语音按钮后出现“语音功能开发中”的 Toast 提示
5. 发送按钮和停止生成按钮行为与当前保持一致
6. 不影响场景选择区域和输入框现有布局

## 风险与边界
- 如果直接重写发送按钮，会引入与 Semi 内部生成态不一致的风险，因此必须复用 `renderActionArea` 传入的默认发送节点
- 如果语音按钮样式完全脱离 Semi footer action button，视觉上会不统一，因此应尽量沿用 Semi 按钮类名或等价样式

## 测试建议
- 手动打开 Chat 页面确认按钮顺序
- 在非生成态检查语音按钮与发送按钮显示
- 在生成态检查语音按钮与停止按钮显示
- 点击语音按钮确认 Toast 提示出现
- 检查上传按钮已隐藏
